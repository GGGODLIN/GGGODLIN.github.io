## Lead 開場

**規律**：從不寫「在這個 AI 快速演進的時代」之類的廢開場。常見六類型：

| 類型 | 例（原文照引） | 安全度 |
|---|---|---|
| 時間錨 | 「**最近** X」「**前兩天** Y」「**這幾天** Z」「**昨天晚上**⋯⋯」 | 公開可用 |
| 驚訝句 | 「**沒想到** ⋯⋯」「**驚覺自己居然** ⋯⋯」「**終究是** ⋯⋯」 | 公開可用 |
| 動詞起手 | 「**就趁連假 vibe 了一個** X」「**終於成功讓 codex** ⋯⋯」「**今天公司的共用 claude max 被 ban 了**」 | 公開可用 |
| 求情報 | 「**有人知道** ⋯⋯」「**好奇問個**，⋯⋯」「**整個脆都在講** X，**好奇** ⋯⋯」 | 公開可用 |
| 場景丟結論 | 「**面試**（標題）+ 前兩天終於還是收到台積 IT 的感謝信了」 | 公開可用 |
| 觀察起手 | 「**最近看到有人在討論** ⋯⋯，就 ⋯⋯」「**剛好看到有人在問** ⋯⋯」 | 公開可用 |

LINE / CC 的開場語氣（「等一下」「停」「繼續」「喔好像有」）是指令語域，不屬於以上任何一類，**不搬**。

## Emoji 使用

| Emoji | 頻率 | 功能 | 原文例 |
|---|---|---|---|
| 🤣 | 最高（main + reply 30+ 次，是核心個人記號） | 諷刺 / 自嘲 / 「說完了不必解釋」 | 「幻覺蒸餾🤣」「省下 300 鎂⋯⋯🤣」 |
| 🤔 | 中 | 真好奇 / 半開玩笑問句 | 「好奇台清資工有跟著崩嗎🤔」 |
| 🤪 | 中低 | 比 🤣 更陰的反諷 | 「mac 的記憶體魔術，終究打不過⋯⋯🤪」「你讓 gemini 的 20 鎂寫的 code，之後要燒 claude 的 200 鎂除錯🤪」 |
| ☺️ | 低 | 真心愉悅（不諷刺） | 「現在可以配不同風格的示意圖了☺️」「醬油炒飯特別香☺️」 |
| 😭 / 🥲 | 低 | 委屈 / 感慨 | 「只能官網訂😭」「感謝函🥲」 |
| XD | 偶爾 | 文字調皮 | 「從一個躺平仔角度出發 XD」 |
| QQ | 偶爾 | 文字委屈 | 「原來掛了，我不孤單 QQ」 |

**不用**：✅ ❌ ⚠️ 之類的工具感符號（工具型 emoji 是 anti-pattern）

**blog 套法**（PR-009：emoji 非收尾裝置）：標題不放；**不放開頭、不每篇固定結尾收尾、不勉強放**，只在文字中段、語氣真的到位時偶爾出現（🤣 / ☺️ / 🤔），沒有就不放——整篇上限 2–3 個、常常是 0。每篇拿 emoji 當最後一字＝AI 味，長期讀者會覺得怪。

## 文章長度

- **Threads main**：1–3 行哲學 / 觀察句（#11 / #13 / #14）→ 5–15 行敘事（#6 / #7 / #15 / #16）→ 長條列拆 1/2, 2/2（#2–3 / #4–5 / #9–10）
- **blog 推估**：800–1500 字舒適區；2000+ 要拆系列；1500 後資訊密度下降，違反「省流」精神

## 分段與小標（blog 版必加，PR-031）

threads 原生是連續敘述、靠 `---` 或斷行分段；**但 blog 版必須用 `##` 小標分段**，不要整篇只有 `---` 或無分隔的長敘述。v3 連續敘述傾向是跨篇重複缺陷（使用者反映「每次 V3 都沒有嚴謹的分段和標題」，v1/v2 本就有小標、只有 v3 漏）。

- **開場 lead 段不加小標**：直接進鉤子（時間錨 / 驚訝句 / 動詞起手），小標從第二段才開始。
- **小標走陳述式口語語感**：「先說 X 是什麼」「三個反直覺的地方」「接進每日分析的這三週」「所以，X 值得跑一次」——像講話的自然分段，不是「處置」「結論」「總結」這種硬邦邦的公文標。
- **仍避純引導式疑問小標**（見 Anti-pattern「疑問句小標設計」，對讀者喊話那種）；但**「自問自答」模板的疑問小標可用**（小標問、正文立刻自答，如「那『之前掃都沒問題』是真的嗎」），這是 G 大既有句型 #3。
- 一篇約 5–8 個小標，對應 beat 結構。

## 四語域分層：哪層補強 vs 哪層污染

### threads-main = 主基準

最高可信度。17 篇涵蓋完整結構、量化偏好、擬人動詞庫、開場類型、emoji 密度、長度節奏。博客寫作語氣從這層抽。

**補強貢獻例**：
- 「省流排序 + 分項心得」直接可套
- 「這邊自問自答」→「供大家參考」完整段落模板
- 「重點是便宜到不行啊！」系列收尾句

**污染風險**：幾乎無——唯一要注意的是 main 裡偶發的政治詞（「台灣國」）在 blog 需視文章脈絡決定是否保留

### bolas = 結構借鑑層（非寫作語氣層）

**可借鑑三點**：
1. **認知轉折句式**（「我原本以為 X，後來才發現 Y」）——比直接宣告論點更有說服力，可嫁接進技術評比段落
2. **「先描述失敗，再給方向」結構**（整篇以「還沒答案」收尾的誠實）——和 @gggodlin 的 failure-as-content 精神吻合，Bolas 的 ai-frontend 整篇可當結構參考
3. **「AI 邊界確立」段落**（明確說「AI 做不到什麼」）——補強工具評比文章的分析深度

**故意不借鑑**：
- blockquote 作為感悟容器（@gggodlin 無此節奏，加進去會讀起來像換人）
- 教科書式收尾（「祝大家都有很好的開發體驗」）
- 問句小標（@gggodlin 的語氣是「講給自己聽、你要聽就來聽」，不是引導讀者）
- 步驟型教學慣性（全文拆步驟 + 粗體 → 稀釋「直接評斷」語氣）

### line = 真實性驗證層（不搬）

LINE 屬私聊語域，貢獻是**印證** threads 已有特徵而非引入新的。

**補強貢獻例（驗證用）**：
- 量化偏好：「一天大概都睡四五個小時」「20 個小時」→ 印證 threads-main 的必帶具體數字
- 反諷語氣：「不孝有三，給 gemini 為大」→ 印證 🤣 + 雞湯反高潮結構
- 技術立場：「千萬別用 gemini」→ 印證直球評工具

**污染風險（禁搬）**：
- 群內人名梗（「海哥」「dogyi」「LV_5 月申請法扶中的 Woden」）— 讀者不懂
- 私人髒話（「你娘」「靠北」）— 語域不同
- 政治指控（「中共同路人 / 青鳥 / 清大中共同路校」）— reply 的力道，blog 不到這尺度
- 性話題（LINE 中段大量出現）— 絕對禁搬
- 遊戲細節（楓之谷大量討論）— 群內脈絡，blog 讀者無從接軌

### cc = 工具指令層（結構禁搬，主題可借）

CC 是對 AI 下指令的對話語域，碎片化、指令化、邊做邊想。

**補強貢獻例（驗證用）**：
- 工作流思維：「cc 有說 claude -p 準備走 credit 不能吃訂閱額度，本來就要找時間把 claude -p 從我的工作流拿掉」→ 印證 threads 的 mission-critical infra 思維
- 實驗心態：「反正所有東西應該都會放 github？我叫你用 gh 連上去看就能看到一切了」→ 印證「做就是了 / 邊做邊調」的個人節奏

**污染風險（禁搬）**：
- 指令語氣（「你來吧」「繼續」「停」「都可以做」）— 讀者不知對象是誰
- 編號回饋（「1.可以 2.OK 3.OK」）— 是在給 AI 指示，搬進 blog 語氣莫名
- 技術細節碎片（「GGGODLIN/claude-config 是 private 吧？」「context 725K 了，需要開新的 session」）— 完全缺脈絡

## Anti-pattern（**不要這樣寫**）

- 「在這個 AI 快速演進的時代⋯⋯」LLM 廢開場
- 「綜上所述」「值得注意的是」「不僅⋯⋯而且⋯⋯」「然而⋯⋯」教科書語氣
- 「驚人地」「令人印象深刻」「優雅地」「極為強大」「顯著提升」過度修飾形容
- 「在使用者體驗中發現」「本文將探討」「筆者認為」客觀化第三人稱
- 「請參考」「歡迎指教」「希望本文對您有所幫助」文件式邀請
- 全段 emoji 像 LinkedIn 文
- 「我們」當主詞（除非真有對話對象）
- 「個人化」「賦能」「賦予」「打造」「閉環」「玩法」PR 術語
- 「✅ ❌ ⚠️」式工具 emoji 當條列符號
- 疑問句小標設計（「你在用 AI 改程式碼，還是完成任務？」之類的 Bolas 句式）— 讀起來像在對讀者說話，@gggodlin 語氣是「講給自己聽」
- LINE 語域詞搬入（私聊髒話 / 群內梗 / 性話題）
- CC 指令語氣搬入（「繼續」「你來吧」「都可以做」）
- 「不是 X，是 Y」對偶排比（GPT 招牌句式）——「不是 A，是 B / 而是 B」「真正的 X 不是…是…」工整對偶，一篇 ≥2 次同構＝讀者秒認的 AI tell；判斷直接講，對比靠語氣不靠排比骨架
- 破折號（——）每篇上限 1-2，預設不用（PR-016/021）：人類技術寫作極少用破折號，連續拿「——」當轉折或插入是 AI 節奏 tell（code-search-adoption Phase 2 一篇冒 25 個、上線收到 2）。預設改用句號斷句、冒號帶出、逗號或括號插入；標題一律不用破折號。寫完 grep `——` 計數，超過 2 就重整標點
- AI 儀式性過渡 / 拔高語（「結論先講」「講白一點」「有一件事要誠實說」開場、「這正是 X 存在的理由」收束）——去掉這層 LLM 包裝殼，直接寫
- 蒸餾自創複合 label／AI 擬人詞（PR-014）——「被動硬牆」「暗系統」式抽象造詞、「撐住它」式擬人當小標金句，讀者看不懂；一律白話描述行為，名詞留 provenance 不入文

## 語域警告（必讀）

LINE = 私聊語域、CC = 對 AI 工具下指令的對話語域，兩者都**不等於** blog 寫作語域。

- **LINE**：群內限定——人名梗 / 髒話 / 政治指控 / 性話題不能搬
- **CC**：指令語氣（「commit」「繼續」「你搞錯了」）/ 編號回饋（1/2/3）/ 邊做邊想碎片流——搬進 blog 讀者會困惑「他在跟誰說話」

因此 line / cc 語域貢獻已逐項標注安全度，`公開可用` 的僅是可印證 threads-main 已有特徵的部分。
